##Proyecto Supabase – ToDo App
#Instalación y ejecución

Paso 1. Descargar el proyecto y colocarlo en una carpeta.

Paso 2. Abrir la terminal y navegar hasta la carpeta del proyecto.

Paso 3. Instalar las dependencias:

npm install

Paso 4. Iniciar la aplicación:

npm run dev

Paso 5. Abrir el enlace que nos aparece en la consola http://localhost:5173
